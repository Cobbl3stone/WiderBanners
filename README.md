# Full Width Banners

A tiny Minecraft mod that fixes one very specific thing that bothered me for way too long:
**vanilla banners are not actually as wide as a full block.**

This mod adjusts the banner model so banners occupy the exact same width as a standard Minecraft block, making them align perfectly with walls, edges, trims, and decorative builds.

Yes, this is an absurdly niche mod.
Yes, I made it anyway.
And if you're here, you're probably part of that niche too.

---

## What This Mod Does

In vanilla Minecraft, banners are slightly narrower than a full block width.
Normally this goes unnoticed, but when building symmetrical structures or detailed interiors, the difference becomes painfully visible.

This mod:

* Expands banner models to full block width
* Keeps the vanilla style and proportions as intact as possible
* Improves alignment in decorative builds
* Makes wall banners and standing banners feel more visually consistent

No new items.
No gameplay changes.
Just wider banners.

## Installation

1. Install your preferred mod loader
2. Download the mod `.jar`
3. Place it in your `mods` folder
4. Launch Minecraft
5. Enjoy unnecessarily accurate banners

## FAQ

### Does this affect hitboxes?

No.
This is purely a visual/model adjustment.

### Does it change textures?

No.
Only the model dimensions are modified.

### Is this really necessary?

Absolutely not.

### Did it annoy me enough to make a mod for it?

Clearly.
